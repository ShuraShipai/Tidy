Nunito and DM Sans are downloaded from Google Fonts and self-hosted. Exact font URLs are preserved in `fonts-source.css`. These families use the SIL Open Font License; license texts are included alongside the fonts.

Icons are authored SVG approximations of familiar iOS symbols. Native implementation should use the corresponding SF Symbols. Clay objects, rings and the storage mark are rendered from CSS geometry and these vector icons. Video preview is an explicitly labeled animated still sequence, not a fetched or compressed video.
